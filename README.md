# Minikeyboard
A small, USB-drive-sized keyboard with four keys: Esc, Tab, Enter, and Ctrl-Alt-Delete. There is room for three additional keys.  

Rev_A is a like a HAT for a Raspberry Pi Pico  

## Note!
*The software is designed for four buttons only.*  
*GPIO2, GPIO4, GPIO6, and GPIO8.*

Rev_B is going to be more like a USB-drive-sized keyboard
